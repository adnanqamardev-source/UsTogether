# Redesign Brief: UsTogether Landing Page

## Goal
Redesign the landing page of UsTogether to increase user engagement, improve conversion rate (sign-ups), and better communicate the product's value proposition.

## Constraints
- Must maintain the existing brand colors (rose-500, indigo-500, and neutral background) and font pairings (Inter and JetBrains Mono) as defined in DESIGN.md.
- Must be responsive and work on mobile, tablet, and desktop.
- Must not break existing functionality (navigation, sign-in button, etc.).
- Must be implementable with the existing tech stack (Next.js, React, Tailwind CSS, Framer Motion).
- Should leverage existing components where possible (e.g., motion.div, use of useAuth, etc.).

## Current Issues (from feedback and metrics)
1. The hero section headline ("How well do you know each other?") is clear but the subcopy could be more benefit-driven.
2. The CTA button ("Get Started Free") is prominent but may benefit from secondary CTA or social proof nearby.
3. The stats section (COUPLES PLAYING, QUIZZES COMPLETED, DAILY STREAKS) is good but could be more visually engaging.
4. The feature sections (Live Quiz Battles, Memory Timeline, Streak & Achievements) use icons and short descriptions but could be improved with better visual hierarchy and possibly micro-interactions.
5. The overall page feels a bit static; adding subtle animations or interactions could increase engagement.

## Desired Outcomes
- Increase sign-up conversion rate by at least 20% (measured via A/B test).
- Improve time-on-page and scroll depth.
- Better communicate the core value: personalized quizzes, real-time competition, and shared memories.
- Make the page feel more dynamic and interactive without being distracting.

## Target Audience
Couples in committed relationships looking for fun ways to connect, communicate, and build shared experiences.

## Key Messages to Highlight
1. Personalized quizzes that grow with your relationship.
2. Real-time quiz battles for playful competition.
3. Memory timeline to revisit and cherish moments together.
4. Streak and achievement system to build habits and celebrate milestones.

## Success Metrics
- Primary: Click-through rate on the main CTA button.
- Secondary: Time on page, scroll depth, and number of users who view at least two feature sections.
- Qualitative: User feedback on clarity, appeal, and likelihood to sign up.

## Additional Notes
- The design should feel warm, intimate, and playful.
- Avoid clutter; maintain ample whitespace.
- Use motion and micro-interactions to draw attention to key elements without being overwhelming.
- Consider incorporating elements of the couple's journey (e.g., a subtle timeline or progress indicator) in the redesign.
