# To-Do List Application ✅

A simple yet functional command-line To-Do List manager built in C++. This application allows users to efficiently manage their tasks with features to add, view, mark complete, and delete tasks.

## Features

- **Add Tasks** — Create new tasks with descriptions and due dates
- **View Tasks** — Display all tasks with their completion status
- **Mark as Done** — Mark tasks as completed
- **Delete Tasks** — Remove tasks from the list
- **User-Friendly Menu** — Simple command-line interface

## Getting Started

```bash
g++ Basic_Functionality.cpp -o todo
./todo
```

## Tech Stack

- **C++** — Core language
- **Standard Library** — Vector, String, I/O
