## What is App Generator?

**App Generator** is a free, secure, and instant document generator designed for Indian users. It helps you create professional official documents — bank applications, police FIRs, office requests, and more — in seconds.

## Features

- **Instant Generation** — Create documents in seconds
- **No Login Required** — Use freely without registration
- **Free Forever** — Completely free to use
- **Multiple Templates** — Bank apps, FIRs, office letters, and more
- **Professional Formatting** — Clean, formatted output ready to print

## Getting Started

```bash
npm install
npm start
```

## Tech Stack

- **Node.js** — Backend runtime
- **NVIDIA NIM API** — AI-powered document generation
- **Axios** — HTTP client
- **dotenv** — Environment configuration
