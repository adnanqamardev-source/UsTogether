# Portfolio HTML 🌐

> **A modern, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript.**

## Features

- **Dark Glassmorphism Design** — Modern aesthetic with animated gradients
- **Interactive Charts** — Visual data representation
- **Smooth Scroll Animations** — Elegant page transitions
- **Fully Responsive** — Works on all devices

## Preview

Open `Portfolio_v4.html` in your browser to view the portfolio.

## Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling
- **JavaScript** — Interactivity
