# COVID-19 Data Visualizer 📊

> **Visualizing the global impact of the COVID-19 pandemic.**

## Overview

This project provides visualizations of global COVID-19 data to help understand the pandemic's impact across different regions. Data is sourced from Our World in Data, which aggregates information from national health ministries and the World Health Organization.

## Features

- **Global Visualization** — See COVID-19 data across all countries
- **Death Rate Analysis** — Deaths per million by continent
- **Interactive Dashboards** — Python-powered data visualization
- **Data Processing** — Clean and process raw data
- **Tested** — Automated test suite included

## Getting Started

```bash
pip install -r requirements.txt
python covid_visualization.py
python dashboard.py
```

## Files

- `covid_visualization.py` — Main visualization script
- `dashboard.py` — Interactive dashboard
- `data_fetcher.py` — Data fetching from OWID
- `data_processor.py` — Data cleaning and processing
- `visualizer.py` — Visualization utilities
- `config.py` — Configuration settings
- `test_modular.py`, `test_all_components.py` — Test suite

## Tech Stack

- **Python** — Data processing and visualization
- **Pandas** — Data manipulation
- **Matplotlib/Plotviz** — Chart rendering
