# Omniroute Server 🌐

> **Node.js server powered by Omniroute.**

## Overview

Omniroute Server is a Node.js application that uses the Omniroute package for routing and data management. Designed for deployment on Render.

## Features

- **Lightweight** — Minimal dependencies
- **Render-Ready** — Deployed on Render
- **Fast** — Node.js runtime
- **Configurable** — Environment-based configuration

## Getting Started

```bash
npm install
npm start
```

## Environment Variables

- `PORT` — Server port (default: 10000)
- `DATA_DIR` — Data directory path

## Tech Stack

- **Node.js** — Runtime
- **Omniroute** — Routing package
- **Render** — Deployment platform
