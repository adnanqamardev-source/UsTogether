# Aura & Co. E-Commerce 🛍️

> **A curated lifestyle boutique e-commerce website built with React, Firebase, and AI.**

## Features

- **Full Shopping Cart** — Add, remove, and manage cart items
- **User Authentication** — Secure login with Firebase Auth
- **Payment Gateway** — Integrated payment processing
- **AI Concierge** — AI-powered product recommendations
- **Order History** — Track your orders
- **Modern UI** — Dark glassmorphism design
- **Real-Time** — Firebase-powered real-time data

## Tech Stack

- **React** + **TypeScript** — Frontend
- **Firebase** — Auth, Firestore, Storage
- **Google GenAI** — AI integration
- **Vite** — Build tool
- **Tailwind CSS v4** — Styling
- **Vitest** — Testing

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

- `api/` — Backend API routes (Gemini chat, payments, auth)
- `src/` — React components and context
- `server.ts` — Server-side logic
- `docs/` — Full documentation (PRD, Architecture, Security)
