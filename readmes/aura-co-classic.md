# Aura-Co Classic 🛍️

> **Earlier version of Aura & Co. E-Commerce.**

## Overview

Aura-Co Classic is the original version of the **Aura & Co.** e-commerce website. It features a React-based shopping experience with product showcase, cart functionality, and authentication.

## Features

- **Shopping Cart** — Add, remove, and manage items
- **Authentication** — User login and registration
- **Product Showcase** — Browse and discover products
- **Checkout** — Order processing flow

## Tech Stack

- **React** — Frontend framework
- **Vite** — Build tool
- **Tailwind CSS** — Styling
- **Lucide React** — Icon library

## Note

This is the classic/earlier version. The current production version is available at **[aura-co-ecommerce](https://github.com/adnanqamardev-source/aura-co-ecommerce)**.
